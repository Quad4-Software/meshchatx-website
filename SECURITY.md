# Security Policy

Report vulnerabilities privately. Do not open a public issue.

- Email: team@quad4.io
- LXMF: f489752fbef161c64d65e385a4e9fc74
- GitHub private vulnerability reporting on this repository

## Scope

This policy covers the code and build of this website
(meshchatx-website). Vulnerabilities in the MeshChatX application itself
are reported in its own repository: Quad4-Software/MeshChatX.
