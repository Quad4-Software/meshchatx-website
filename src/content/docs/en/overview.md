MeshChatX is a local-first mesh communications client on the Reticulum Network Stack. It combines LXMF messaging, LXST voice calls, NomadNet browsing, relay chat, maps, and Reticulum utilities in one app for desktop, headless servers, and mobile.

These guides are adapted from the MeshChatX application docs bundle in the [Quad4-Software/MeshChatX](https://github.com/Quad4-Software/MeshChatX) repository. The in-app **Documentation** page ships the same material for offline use.
